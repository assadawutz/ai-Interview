# Interview Pulse 4 · Focused workspace

The main job is question → answer → evidence check. Four destinations only:
Workspace, Profile, Sessions and System. No secondary chat or separate planning/
practice flow. Old session fields remain readable and exportable without mounting
retired feature modules.

Mobile shows the question/answer first, then the queue, with four bottom navigation
items. Desktop shows the answer on the left and the queue on the right. Navigation
moves to the top. Check 320, 390, 768, 1024 and 1440 px without horizontal overflow.

Light neutral surfaces, restrained lime primary actions and purple context accents.
No decorative SVG, background effects, floating text, animated gradients or tilt.
Only functional busy indicators remain and honor reduced-motion preferences.
Advanced answer controls use a native collapsed details element.

The only runtime is a static browser client. No Express, server credentials,
server transport switch, app access token or hidden CORS proxy. Provider SDKs load
on demand. Preserve Zod validation, timeout/cancellation, independent fallback,
explicit completion, stale-context protection and evidence checks.

Keep visible keyboard focus, input labels, named icon navigation, the skip link and
Thai-font print output. Never suppress console errors. Provider/network failures
must remain actionable. Keys default to sessionStorage, with explicit localStorage
opt-in. No credential belongs in public config, logs or session exports.
